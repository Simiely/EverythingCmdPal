# CHANGELOG

所有版本的变更记录。格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)。

## [1.3.4] - 2026-10-26

- 新增：文件夹「浏览」页。文件夹结果的 `Ctrl+K` 菜单多一项「浏览文件夹」，
  列出该文件夹的直接子项（Everything `parent:"路径"` 官方语法），搜索框变成
  在当前文件夹内筛选，排序/分页/预览/连接诊断全部沿用
- 重构：`ResultsPage` 去密封并加 `ToEverythingQuery` 钩子与可覆盖空态文案，
  浏览页以子类实现（12 行核心逻辑），`ResultContext` 加 `FolderBrowseFactory`
- SelfTest 新增 3 条浏览查询构造断言（共 27 项全过）；
  QueryTest 实测 `parent:` 经 SDK3 返回直接子项 13/13

## [1.3.3.3] - 2026-10-26

- 修复：连不上 Everything 时一律落到「没有找到结果」，看不出原因。现在区分两种失败——
  「Everything 未运行」与「进程在但拿不到 1.5 管道（1.4 / 实例名不符 / 未开 `allow_ipc_pipe`）」，
  各给可操作提示；连上但没搜到时改为提示换关键词或 Everything 语法
- 修复：预览缓存（`%TEMP%\EverythingCmdPal\preview`）只增不减。新增 300 条 / 256 MB 上限，
  超限按最后写入时间淘汰最旧的（尽力而为，被占用的文件跳过）
- 文档：设置项「Everything 实例名」说明改为「留空自动检测（1.5 alpha 期需填 1.5a；beta/正式版会恢复默认实例名）」
- 文档：PLAN §12 四条待确认按官方一手依据定案（预览形态 / fallback 默认 / 拖拽文本 / 1.4 通道），
  并补齐 P2 四项处置
- 工具：`tools/QueryTest` 新增 `--probe` 连接探针；`tools/SelfTest` 新增 6 条连接诊断断言

## [1.3.3.2] - 2026-10-26

- 回退：移除 1.3.3.1 的跨实例 `SearchText` 同步。写 `SearchText` 会让宿主再次触发页面搜索，形成往返循环导致持续闪烁

## [1.3.3.1] - 2026-10-26

- 修复：GoBack 返回后搜索框文字消失。原因：详情页与隐藏详情页是两个实例，前者从未被同步过文本。
  现在纯列表页打字会把文字写回下层详情页（页不在前台，不触发全选）；进入隐藏详情页前也会回填 `SearchText`

## [1.3.3] - 2026-10-26

- 修复：来回切换「隐藏详细信息 / 显示详细信息」后返回栈越切越深，需连按多次返回才能退出。
  回程改用 `CommandResult.GoBack()` 弹栈，栈深恒定；详情页实例保留，其搜索框文本随之保留

## [1.3.2.4] - 2026-10-26

- 回退：移除 `SearchText` 回填。宿主文本框被程序化赋值后强制全选，扩展 SDK 无光标/选区控制接口，保留「隐藏详情」改名，其余恢复 1.3.2.2 行为

## [1.3.2.3] - 2026-10-26

- 文案：无详情页页面名「纯列表」改为「隐藏详情」
- 修复：切换页面后搜索框文字被清空——导航前把当前查询写回 `SearchText`

## [1.3.2.2] - 2026-10-26
